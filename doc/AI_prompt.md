# 第1轮
从0开始开发游戏，游戏名字叫妖怪偷宝石（项目名monster_vs_gem），运行于单机PC浏览器，html+js，属于塔防闯关类，核心玩法是玩家使用道具，阻止妖怪偷到宝石。
游戏开始，左侧是宝石，妖怪从右侧进入画面，向宝石移动，前2关，玩家可使用的道具包括：

棍子：减慢妖怪移动速度。
2.手雷：减少妖怪生命值（满值100，每次减少10，减到10后，每次减少5）。
用html开发，代码可读性好，
素材目录清晰，方便替换，偏卡通风格，文字易阅读，可以先开发2关试玩。

# 第2轮
有几处需要优化：
- 妖怪移动速度太快，影响游戏体验
- 前2关妖怪数量太多，建议少于3个，先保证可玩性

再出一版，玩玩再给你反馈

# 第3轮
可玩性有了提升，还需要如下优化：
- 棍子道具的方向比较随机，需要统一成竖直屏幕方向，有效阻挡怪物
- 怪物头顶血条同时显示生命值
